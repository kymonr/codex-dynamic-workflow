# Luna exploration uses native agents

The user superseded the independent CLI pool with native-only delegation.
Luna exploration, verification and Astra work all use native host agent tools.
See [host routing](host-routing.md) for profiles and capability checks, and
[budget](budget.md) for shared native capacity, useful batches and required reviews.

The former CLI pool is not an active route. Public model-dispatch commands and
new exec plans are rejected. Existing exec records and regression modules remain
for inspection and compatibility, without authorizing new model calls.

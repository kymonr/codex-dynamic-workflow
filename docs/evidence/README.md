# Evidence Directory

此目录用于保存支持 Team Router 审查、验证和 closeout 决策的小型、可版本化证据。

适合放在这里：

- 手动检查的 Markdown 摘要。
- 对后续审查有用的 JSON 或 TXT 命令摘要。
- 解释为何排除无关 untracked artifacts 的 inventory。

不要放在这里：

- 生成图片批次。
- 动效帧、contact sheet、spritesheet 或 preview。
- 大型二进制快照。
- 仍需 owner 确认的本地资产。

本地图片生成输出应保留在 ignored 的 `/pet-runs/` 或根目录 `/ig_*.png`，除非后续任务明确提升某个已审查资产。
